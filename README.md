# Python Lab Programs

This repository contains beginner-friendly Python lab exercises. Each file is a small standalone script focused on one programming concept such as input/output, conditionals, functions, recursion, lists, tuples, exception handling, file operations, and basic class usage.

## Repository Contents

### Basics and conditionals

- `1Basic_input_output.py` - reads name and age, then prints them
- `2if_else.py` - checks voting eligibility using `if`/`elif`
- `check_positive_negative_zero.py` - identifies whether a number is positive, negative, or zero
- `print_largest_num.py` - prints the largest among three numbers
- `prime_num.py` - checks whether a number is prime

### Loops, recursion, and functions

- `3factorial.py` - factorial using a loop
- `factorial_using_function.py` - factorial using a function
- `4Func_calculate_area.py` - calculates the area of a circle
- `fibonacci_series.py` - builds a Fibonacci series recursively
- `power_using_recusrion.py` - defines a recursive power function
- `running_sum.py` - keeps summing positive numbers until a negative number is entered
- `concatenate_strings.py` - joins first and last name into a greeting

### Lists and strings

- `5sort_list.py` - sorts a list manually using nested loops
- `6reverse_string.py` - reverses a string without slicing
- `list_input.py` - accepts student marks and calculates average
- `max_in_list.py` - finds the maximum value in a list
- `pos_neg_list.py` - separates positive and negative values
- `frequency_of_num.py` - counts the frequency of a number in a predefined list
- `in_operator.py` - checks whether a number exists in a list and shows its index

### Tuples

- `tuple_operations.py` - extracts usernames and domains from email addresses
- `tuple_search.py` - searches for a name in a tuple

### Exceptions, files, and classes

- `7exception_handling.py` - demonstrates `try`/`except`/`else`/`finally`
- `8file_handling.py` - reads `input.txt` and writes data to `output.csv`
- `9binary_file_operations.py` - stores and reads binary data using `pickle`
- `9class_usage.py` - basic class and object example using a `Car` class

## Requirements

- Python 3.x

## How To Run

Run any script from the repository folder:

```bash
python 1Basic_input_output.py
```

If your system uses `python3`, run:

```bash
python3 1Basic_input_output.py
```

## Notes

- This repository is a collection of independent lab programs, not a single integrated application.
- Most scripts are interactive and require keyboard input.
- Some scripts define functions only and may need a function call added if you want visible output immediately.
- A few programs use fixed sample lists or tuples to demonstrate the concept clearly.
