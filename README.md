# Python Lab Programs

This repository contains beginner-friendly Python lab exercises and tutorial programs. Most files are small standalone scripts focused on one concept at a time, such as input/output, conditionals, loops, functions, recursion, lists, tuples, exception handling, file handling, and basic class usage.


## Topics Covered

- Basic input and output
- Conditional statements
- Loops and iterative logic
- Functions
- Recursion
- String operations
- List and tuple exercises
- Exception handling
- Text, CSV, and binary file handling
- Basic object-oriented programming

## Requirements

- Python 3.x

## How to Run

Run any script from the repository folder:

```bash
python 1Basic_input_output.py
```

If your system uses `python3`, run:

```bash
python3 1Basic_input_output.py
```

## Notes

- This repository is a collection of individual practice programs, not a single integrated application.
- Most scripts are interactive and ask for keyboard input when run.
- A few files are function-focused examples and may not print output unless you add a call yourself.
